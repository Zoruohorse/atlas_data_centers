## Suite de l'audit par un agent

1. Vérifier les P1 puis les P2 dans les sources primaires actuelles ; comparer les versions et les dates.
2. Qualifier chaque signal comme confirmé, infirmé, incertain ou non pertinent avec URL, date et justification.
3. Créer un delta sourcé uniquement pour les évolutions confirmées ; conserver les entrées historiques.
4. Rechercher en complément les contradictions de fond, les liens manquants et les angles morts selon le [protocole](../../docs/maintenance/audit-semantique.md).
