# Analyses transversales capitalisées

Ce dossier est destiné aux analyses produites à partir de l'atlas et expressément retenues pour une conservation publique. Aucune analyse ad hoc supplémentaire n'est publiée pour l'instant ; consulter les [fiches de concepts](../index.md).

## Format recommandé

- Titre, question stratégique, date de rédaction et date de révision des données.
- Périmètre (pays, période, critères), méthode et limites.
- Constats factuels avec identifiants des entrées et liens sources primaires.
- Comparaison, interprétation et hypothèses explicitement distinguées.
- Points à surveiller et condition de révision.

Nommer les fichiers `AAAA-MM-JJ-sujet.md`, ajouter leur lien ici, conserver les versions dans Git et signaler toute actualisation. Ne pas publier de document interne, de contenu sous licence ou de données confidentielles. Les analyses n'alimentent pas directement la carte : seuls les deltas vérifiés des JSON le font.
